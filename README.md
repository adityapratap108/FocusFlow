# 🚀 FocusFlow - Kanban Task Manager

FocusFlow is a sleek, intuitive Kanban-style task management application designed to streamline your productivity. It features a modern dark-themed UI with purple accents, persistent local storage, and seamless drag-and-drop functionality.

![FocusFlow Preview](https://via.placeholder.com/800x450?text=FocusFlow+Kanban+Board+Preview) 

## ✨ Features

- **Drag-and-Drop Interface:** Easily move tasks between "To Do", "In Progress", and "Completed" columns.
- **Persistent Storage:** Your tasks are saved to `localStorage`, so they stay there even if you refresh or close the browser.
- **Dynamic Task Counting:** Real-time counters for each column to track your workload.
- **Responsive Design:** Optimized for desktops, tablets, and mobile devices.
- **Onboarding Hint:** A smart "first-visit" hint to teach users about the drag-and-drop feature.
- **Custom UI:** Hand-crafted CSS animations, custom scrollbars, and glassmorphism effects.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure.
- **CSS3:** Custom properties (variables), Flexbox, Animations, and Media Queries.
- **JavaScript (ES6):** DOM manipulation, Drag & Drop API, and LocalStorage.
- **Font Awesome:** For professional iconography.
